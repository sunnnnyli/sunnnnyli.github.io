## About this repo

This is the source for my portfolio. It's one page covering my work at Justworks, NYC's Office of Technology and Innovation, and Olympix, plus a few projects along the way.

I kept it to plain HTML, CSS, and JavaScript, with no framework and no build step. GitHub Pages serves the files exactly as they are here.

## Details I cared about

| | |
| --- | --- |
| **Light and dark themes** | Follows your system setting, and the toggle remembers your choice |
| **Motion with an off switch** | Scroll-driven animations that respect your system's reduced-motion setting, plus a toggle in the nav |
| **Smooth on phones** | Touch screens get lighter effects so scrolling stays smooth |
| **Accessible** | Skip link, native dialogs, keyboard focus styles, and alt text |
| **Prints cleanly** | A print stylesheet turns the page into a tidy light document |
| **Shares well** | Link previews, structured data for search, a sitemap, and a custom 404 page |

## What's where

```
index.html              the page
404.html                shown for any address that doesn't exist
Sunny-Li-Resume.pdf     my résumé
assets/css/styles.css   styles for both themes
assets/js/main.js       scroll effects, theme and motion toggles, copy-email button
assets/img/             profile photo, company logos, link-preview image
assets/icons/           favicons and app icons
```

The root also holds the files browsers and search engines look for: `favicon.ico`, `apple-touch-icon.png`, `site.webmanifest`, `robots.txt`, `sitemap.xml`, and `.nojekyll`.

## Running it locally

Open `index.html` in a browser. To serve it the way GitHub Pages does, run this from the repo folder and visit http://localhost:8000:

```bash
python -m http.server
```
